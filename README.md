# oocollective.org

Published pages for the OO Pickleball Collective, served by GitHub Pages
with HTTPS. Do not edit by hand: `~/collective-engine/scripts/publish-week.sh`
regenerates `index.html` (this week) and `booker.html` (the bookers' sheet)
from SCHEDULE-LOG.md and pushes here.

- `CNAME` — tells GitHub Pages the custom domain; keep it.
- `.nojekyll` — serve the files as-is, no Jekyll processing.
